# ContextFlow — Technology Stack

| Layer | Technology | Purpose |
|---|---|---|
| **Mobile Frontend** | React Native (Expo / JS) | Clean actionable agent UI dashboard |
| **Backend Server** | Node.js + Express (JS) | Life assistant API & Context Fusion |
| **AI Model** | Ollama (`llama3.2:1b`) | Local 1B parameter AI model on `127.0.0.1:11434` |
| **Learning Memory** | Node.js Memory Store | Preferences & learned behavioral rules |
| **Context Services** | Location, Calendar, Traffic, Clipboard | Multi-modal context engine |
